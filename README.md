# Password Generator

## Description

This is a simple password generator web application built with React.  It allows users to generate random passwords with customizable options such as length, inclusion of numbers, and special characters.

## Features

* **Password Generation:** Generates a random password based on user-defined criteria.
* **Customizable Length:** Users can specify the desired length of the password (between 6 and 100 characters).
* **Include Numbers:** Option to include numeric characters in the generated password.
* **Include Special Characters:** Option to include special characters in the generated password.
* **Copy to Clipboard:** A button to easily copy the generated password to the clipboard.
* **User-Friendly Interface:** Clean and intuitive design.

## Technologies Used

* React
* Tailwind CSS (for styling)

## Installation

Since this is a web application, there's no traditional installation.  To use it:

1.  **Clone the repository (Optional, if you want to run it locally):**
    ```bash
    git clone <repository_url>
    cd password-generator
    ```
2.  **Install dependencies (Optional, if you want to run it locally):**
    ```bash
    npm install
    ```
3.  **Run the application (Optional, if you want to run it locally):**
    ```bash
    npm start
    ```
4.  **Access the application:** Open your web browser and navigate to the deployed application URL (or `http://localhost:3000` if running locally).

## Usage

1.  **Length:** Use the slider to select the desired length of the password (between 6 and 100).
2.  **Options:**
    * Check the "Numbers" checkbox to include numbers in the password.
    * Check the "Characters" checkbox to include special characters in the password.
3.  **Generate:** The password will be automatically generated and displayed.
4.  **Copy:** Click the "Copy" button to copy the generated password to your clipboard.
